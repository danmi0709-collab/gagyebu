💰 가계부 앱 사용 설명서

1️⃣ 내역 탭

  • 날짜 · 카테고리 · 금액 · 메모 입력 후 저장
  • 자연어 입력 가능: "배스킨라빈스 변동 외식 4700원"
  • 월 ◀ ▶ 버튼으로 다른 달 조회
  • 카카오페이 내역 붙여넣기 자동 파싱 지원

2️⃣ 분석 탭

  • 저축률 · 그룹별 예산 대비 실적 코멘트
  • ◀ ▶ 로 지난달 분석도 확인 가능

3️⃣ 카테고리 탭

  • 고정/변동/교육/비정기 예산바 + 도넛 차트
  • 고정지출 체크박스 클릭 → 내역 자동 등록

4️⃣ 연예산 탭

  • 연간 수입/지출/저축 항목별 예산 입력
  • 수식 지원: 22만, 22.5만, 30*12 등
  • 수입 대비 % 분류 (고정지출 몇%, 저축 몇%) 자동 계산
  • 아래로 스크롤하면 연간 진행 현황 확인 가능

5️⃣ 자산 탭

  • 자산(현금·적금·주식·부동산 등)과 부채 입력
  • 순자산 = 자산 − 부채 자동 계산

6️⃣ 구독 탭

  • 구독 서비스 등록 · 수정 · 해지
  • 매달 1일 자동으로 내역 탭에 등록
  • 7일 이내 결제 예정 알림
  • 월간 / 3개월 / 6개월 / 연간 주기 지원

💾 데이터 관리

  • 데이터는 이 기기 브라우저에만 저장됩니다
  • 내역 탭 하단 JSON 내보내기로 정기 백업 권장
  • 브라우저 데이터 삭제 시 내역이 사라질 수 있어요

📋 구글 시트 연동 설정 방법
  1. 구글 시트를 하나 새로 만드세요.
  2. 상단 메뉴 → 확장 프로그램 → Apps Script 클릭
  3. 기존 내용 지우고 구글시트_스크립트.gs 파일의 내용을 붙여넣기
  4. 저장(💾) 후 → 배포 → 새 배포 클릭
  5. 유형: 웹 앱, 액세스: 모든 사용자 선택 후 배포
  6. 생성된 URL을 위 입력창에 붙여넣고 URL 저장
